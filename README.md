## Machine Learning Model for Root Cause Analysis of L1 DU Stats
### Categories
- Good UE Sessions **Low BLER, good channel quality, good MCS**
- High BLER Good Channel **RV0 Transmissions very low**
- Bad Channel Quality **HIGH BLER due to bad channel quality, low CQI**
- Scheduler MCS Limitation **Capped MCS while good channel and many RV0 transmissions**
